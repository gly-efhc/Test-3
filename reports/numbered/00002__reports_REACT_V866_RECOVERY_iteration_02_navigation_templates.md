## Выполнено в одном связанном блоке

1. Устранено удержание Admin renderer после смены маршрута. Доказанная причина:
   сохранённый `adminVisualProofPath` оставался активным после ухода из Admin.
   Добавлен явный выход «В приложение», восстанавливающий корневой маршрут.
2. Объединены экранный, браузерный, Telegram и Android Back. Удалены конкурирующие
   Telegram-обработчики Layout/списка рефералов. Сначала закрывается верхнее
   модальное окно или отменяется черновик настройки; затем выполняется переход.
   Прямо открытая дочерняя страница Admin возвращается в меню, затем в приложение.
   Нормализация завершающего слеша исключает цикл между дочерней страницей и меню.
3. Обработаны пропуск первого same-URL popstate в Next.js и повторная обработка
   одного Back. Закрытие модального окна профиля сохраняет URL профиля. Режим
   настройки Admin учитывается по атрибуту его собственного React-контейнера.
   Для Android/WebView доступны `__EFHC_ANDROID_BACK__`, `__EFHC_ANDROID_EXIT__`
   и событие `backbutton`. В Telegram корневой выход закрывает host; обычный
   браузер использует свою историю. Физический Android этим не сертифицируется.
4. Внутренние переходы профиля, Withdraw, возврат с 404 и вход в профиль из
   Browser Shop переведены с абсолютных URL на Next Router с Pages basePath.
5. Admin получает полную доступную ширину с первого рендера. На телефонах
   длинный заголовок и кнопки размещаются отдельными строками без наложения.
   Проверены фактические ширины контейнера и отсутствие пересечения текста
   с действиями до/после взаимодействия. Визуально просмотрен снимок 390px.
6. Шестерёнка и соседний переключатель привязаны к правому краю собственной
   оболочки, учитывают safe-area и высоту нижнего меню. Заставка занимает экран;
   её центральный блок масштабируется до 78vmin с ограничением по высоте.
7. Исправлено владение жестом вложенных шаблонов: PB получает свой жест внутри
   EG, а readonly XS не блокирует выбор родительского XH. Referrals использует
   RG, профиль — PM и соответствующий CSS-контейнер, History — свой authored
   класс. KG использует каноническое отображение selection в физический стиль.
8. Добавлены обязательные CI-наборы взаимодействий, циклов шаблонов и маршрутов.
   Header/HUB остаются принятыми компонентами; новые проверки защищают их вместе
   с десятью темами и исходными контрактами HTML.
