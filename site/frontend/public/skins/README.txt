EFHC WebApp Skins

Папка для картинок на главной странице.

Канон совместимости:
  /skins/<N>.webp

Где N — целое число (1,2,3,...). Чтобы заменить исходную картинку,
перезапишите PNG файл тем же номером.

Оптимизированный first-paint runtime:
  /skins/1.webp

Для первого экрана разрешён WebP-вариант, чтобы не грузить тяжёлый PNG
до отображения интерфейса. Старый PNG compatibility/source asset удалён.

Важно:
- Рекомендуемый баннер: 1200x520 или близкое соотношение.
- First-paint asset должен быть максимально лёгким.
- Бот/skin hero не должен блокировать первый экран.
- Открытие и активация выполняются через Hub → Skins.
