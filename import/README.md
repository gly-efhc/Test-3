# EFHC — импорт исходников DEMO

Эта папка предназначена **только для загрузки нового ZIP-архива React-фронтенда EFHC**.

## Обновление

1. Загрузите один актуальный архив `FRONTEND_DEMO_IMPORT_vNNN.zip` в эту папку без распаковки.
2. Сохраните изменение в ветке `main` (Commit changes).
3. GitHub Actions (`.github/workflows/efhc-pages.yml`) проверит архив, обновит необходимый код React и попытается собрать GitHub Pages.
4. После успешного импорта и сборки workflow удалит загруженный ZIP из `import/`. Этот файл `README.md` останется.

**Правила:** в папке должен находиться не более чем один ZIP-архив одновременно. Не размещайте здесь секреты, рабочие документы, логи и backend. При ошибке сборки ZIP сохраняется для диагностики и повторного запуска.

> Публикация GitHub Pages предназначена для безопасного DEMO без реальных финансовых операций. Реальная сборка Next.js и совместимость страниц требуют проверки в GitHub Actions.
